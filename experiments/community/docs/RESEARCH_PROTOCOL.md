# 任务条件数据选择协议

以固定基准训练集D0为基础，从公共候选池选择k条新增数据。每个选择臂使用相同D0、目标模型、训练预算和评价成员。分类使用LogisticRegression(C=1, solver=lbfgs, max_iter=500, tol=1e-5)，回归使用Ridge(alpha=1)。D0拟合填补和缩放，不能利用开发或评价数据拟合预处理。

选择比较包括随机、组覆盖、来源版本证据、RF来源符合性及其组合、完整率、距离和固定质量分；回归补充8个完整排列的条件MC Data Shapley。来源对照只比较同一来源版本，不能证明自然内容真实。RF由D0受控扰动监督，不能称作自然缺陷事实模型；Shapley可使用开发集标签，带来额外信息及成本。

选择完成后冻结成员和摘要，再对开发、评价成员逐条保存模型输出。回归指标为MAE、RMSE、R²；分类为LogLoss、Accuracy、Macro-F1。当前标准执行器不计算二分类AUROC，记为NOT_EVALUATED；如另行提供，校验器只在条件适合时复算。主要效用增量是相同评价集上的`D0损失 - 加入所选数据后的损失`；正数表示损失下降，负数必须保留。每个数据集单独解释其指标单位，不把分类和回归损失直接平均。

分组隔离和公开评价集不能提供隐藏盲测保证。后续方法调整产生的新结果属于开发过程；真正的独立最终测试须以新协议由维护者控制。详细任务和结果提交见`docs/EXPERIMENT_TASK_MATRIX.md`与`docs/RESULT_SUBMISSION.md`。
