# 复现与结果验收政策

## 固定条件

一个运行绑定任务、源数据和版本、数据成员与分组、D0/候选池/开发/评价划分、随机种子、候选预算、所有训练臂、模型和主要指标。预处理只根据D0拟合；方法选择应在读取评价标签之前冻结。受控来源修改真值用于全部选择、拟合和评价完成后的诊断，不是对自然标签正确性的认证。

三个种子均应保留，重复运行不得因结果不利被删除；若某个臂或某个种子失败，保留错误日志并报告缺失。变更方法、指标、划分、模型或预算需要新的协议和版本，不覆盖现有配置。Data Shapley回归基线使用开发集标签，信息和计算成本需单独列示，不能称作与全部基线拥有完全相同信息。

本批公开数据的评价标签可由公开来源获得，执行顺序可验证并不构成保密盲测。未来真正独立的最终测试需由维护者单独控制，不随任务发布答案或注入真值。多次运行同一数据集仅用于复现和稳定性分析，不构成多个独立数据集；不同量纲指标不得直接求平均。高维质量统计、来源版本一致和任务适配也不能替代真实模型训练收益。

## 状态解释

| 状态 | 含义 |
| --- | --- |
| SUBMITTED | 已提交结果，尚未完成检查 |
| SCHEMA_VALID | 必需字段和文件结构通过，不表示实验有效 |
| REPRODUCED | 在可信数据和约定范围内，逐项数值与结果可以复算 |
| NEEDS_REVIEW | 信息缺失、自动检查覆盖不足或需要人工复核 |
| REJECTED | 明确违反协议或数据/结果校验失败，保留原因 |
| SCIENTIFICALLY_ACCEPTED | 维护者完成独立协议、成员与成本复核后手动认定；自动CI不能单独授予 |

哈希绑定的是字节，不证明数据真实性、贡献者身份或执行过程。记录中声称某个版本、模型或机器并不能单凭自报认证；维护者可要求独立重跑、原始日志、已授权的计算环境信息或其他非敏感证据。自动检查不运行外部提交的任意程序、不执行pickle；对于无法安全验证的材料保持NEEDS_REVIEW。

## 信息和成本

来源可信、结构质量、组覆盖和任务效用各自报告来源与分母；缺少真实事实真值时保持未知。受控扰动的F1与训练效用预测相关性不同。Spearman及成本百分比只能在足够独立来源和明确定义的完整比较流程下计算；同源多个策略点、部分计时或不同硬件时间不能充当对应证明。发布汇总时保留所有条件、失败、额外信息、风险和负收益。

执行器的1800秒累计账本只约束单个输出父目录中的本机运行，并不能自动同步不同目录、不同贡献者或不同机器。跨运行成本和协议边界由维护者合并记录；不能称这一账本提供全局限制。
